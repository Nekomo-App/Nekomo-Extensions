# Security guidelines

Third-party extensions and sources are independent software. Treat them as untrusted unless you have reviewed and verified their origin.

## Safer usage

- Prefer official developer repositories and release channels.
- Review permissions and source code when possible.
- Be cautious of unexpected login prompts, redirects, or requests for personal information.
- Keep Nekomo, Android, and extensions updated.
- Do not share passwords, session cookies, API keys, or access tokens in issues.

## Reporting a security concern

Do not publish exploitable details in a public issue. Contact the Nekomo maintainers through the project's official community or security contact, if one is published.

This repository does not audit or certify third-party extensions. A compatibility result is not a security endorsement.
