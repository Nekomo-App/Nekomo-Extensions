# Contributing

Contributions to documentation and compatibility notes are welcome.

## Before contributing

- Check whether the information already exists.
- Use clear, neutral language.
- Distinguish tested facts from assumptions.
- Do not upload third-party extension packages, copyrighted content, credentials, or private user data.

## Compatibility reports

Include the Nekomo version, Android version, ecosystem, extension name and version, test date, status, and reproduction steps.

## Documentation changes

Keep instructions current and avoid promising compatibility that has not been tested. When possible, link to the upstream developer's official documentation rather than copying it.
