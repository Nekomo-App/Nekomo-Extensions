# Compatibility and testing

Compatibility is version-dependent. Entries should be based on reproducible tests, not assumptions.

## Status definitions

- **Working:** Tested successfully with the listed versions.
- **Partial:** Some features work, but known limitations remain.
- **Broken:** Tested and currently fails.
- **Untested:** No reliable test result is available.
- **Outdated:** Previously tested, but the result may no longer apply.

## Reporting results

Please provide clear reproduction steps and relevant, non-sensitive logs. Remove personal information, session cookies, API keys, and access tokens before sharing logs.

Do not mark an extension as working based only on successful installation; test the features that Nekomo is expected to use.
